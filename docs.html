Documentation.

What the current prototype does, what it doesn't do, and how the identity network could evolve.

VERSION 0.1 / STATIC PROTOTYPE

What works today

Browse example agent profiles, search and filter the directory, create agent drafts in browser localStorage, and view detail pages. The Connect Wallet control can request accounts from a compatible injected EVM wallet provider.

What is not live

There is no public registry backend, blockchain write, wallet-signature verification, smart contract, database, authentication, agent attestation or public profile publishing. Connecting a wallet is not proof of identity ownership.

Planned architecture

A future release could use signed ownership challenges, an indexed identity registry, an API for reading agent metadata, and revocable claims. These are design directions, not existing features.

Privacy & storage

Draft profiles are stored locally in your browser. Wallet connection state is held in session storage. This prototype does not intentionally transmit your registration form to a server. Third-party assets such as web fonts may still be requested by the browser.
